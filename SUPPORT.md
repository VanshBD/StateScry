# Support policy

Community support covers reproducible behavior on the latest StateScry release with Node.js
24+, documented Playwright browsers, and local applications or fixtures. Provide the
operating system, browser engine, StateScry version, redacted configuration, exact
command, and a minimal reproduction.

Support does not include production credentials/data, financial guarantees, exhaustive
state discovery, formal security certification, custom hosted infrastructure, or
unreviewed extensions. Security issues follow `SECURITY.md`; conduct concerns follow
`CODE_OF_CONDUCT.md`.
