# StateScry brand assets

These assets derive from the project owner's approved StateScry brand board.

| Asset                                | Purpose                                                                                                            |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------ |
| `statescry-brand-board.png`          | Original approved visual source; do not modify in place                                                            |
| `statescry-mark.png`                 | Transparent standalone product mark                                                                                |
| `statescry-app-icon.webp`            | Exact cropped app-icon treatment from the approved board                                                           |
| `statescry-lockup-dark.webp`         | Cropped, optimized dark wordmark used at the top of the repository README                                          |
| `statescry-behavior-graph-hero.webp` | README product illustration showing application mapping, behavior graph, replay, diff, evidence, and agent context |
| `statescry-social-preview.webp`      | 1280×640 repository social-preview artwork for GitHub settings                                                     |
| `apps/dashboard/public/brand/*`      | Dashboard logo, browser favicon, and touch-icon derivatives                                                        |

Use `StateScry` for the product wordmark and `statescry` for CLI/package identifiers.
Keep clear space around the mark, preserve its emerald/mint palette and node topology,
and do not stretch, rotate, recolor, or place it on a low-contrast background.

The README hero was generated from the approved brand language with OpenAI's built-in
image-generation tool. It is illustrative product artwork, not a screenshot or benchmark
result.
